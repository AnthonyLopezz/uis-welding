Quiero que construyas una **plataforma web interactiva de aprendizaje** utilizando como fuente de conocimiento los datos extraídos y estructurados de los PDFs disponibles en el proyecto.

La finalidad NO es crear un simple visor de documentos.

Quiero transformar todo el contenido extraído en una **experiencia de estudio interactiva**, donde el usuario pueda aprender los temas progresivamente, consultar imágenes, responder preguntas, revisar errores y medir su progreso.

La interfaz debe ser sencilla, limpia, moderna y responsive, inspirada visualmente en la identidad institucional de la **Universidad Industrial de Santander (UIS), Colombia**, sin copiar literalmente su sitio web.

---

# 1. Objetivo de la aplicación

La aplicación debe permitir al usuario:

* explorar todos los temas disponibles
* estudiar por categorías
* estudiar por temas
* leer contenido estructurado
* visualizar imágenes asociadas al contenido
* consultar tablas
* responder preguntas durante el estudio
* recibir retroalimentación inmediata
* repetir preguntas incorrectas
* marcar temas como completados
* visualizar su progreso
* identificar temas débiles
* continuar donde dejó el estudio
* realizar sesiones de repaso
* realizar evaluaciones
* buscar contenido
* navegar fácilmente entre temas

La experiencia debe sentirse más como una **plataforma educativa interactiva** que como una biblioteca de PDFs.

# 13. Sistema de preguntas

Genera preguntas utilizando exclusivamente el contenido de los datos extraídos.

NO inventes conocimientos externos.

Tipos de preguntas:

### Selección múltiple

```text
¿Cuál es...?

○ A
○ B
○ C
○ D
```

### Verdadero / falso

```text
La afirmación X es correcta.

[Verdadero] [Falso]
```

### Relacionar conceptos

Cuando los datos permitan hacerlo.

### Identificación mediante imagen

Cuando una imagen sea apropiada:

```text
Observa la imagen.

¿Qué representa?

[ A ]
[ B ]
[ C ]
[ D ]
```

### Pregunta basada en tabla

Utilizar los datos de las tablas extraídas.

---

# 14. Calidad de las preguntas

Las preguntas deben evaluar comprensión, no solamente memoria literal.

Prioridad:

1. comprensión
2. aplicación
3. identificación
4. relación entre conceptos
5. memoria

Cada pregunta debe tener:

```ts
{
  id: string;
  topicId: string;
  type: "multiple-choice" | "true-false" | "image" | "matching";
  question: string;
  options?: string[];
  correctAnswer: string;
  explanation: string;
  difficulty: "easy" | "medium" | "hard";
  sourcePage?: number;
}
```

La pregunta debe poder rastrearse hasta el contenido que la originó.

## 47. Configuración netlify.toml

```text

```

con una configuración equivalente a:

```toml
[build]
  command = "npm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

No dupliques configuraciones innecesariamente entre `netlify.toml` y `_redirects`. Elige una estrategia coherente.
